## What defines a slot

Most trackers split slots along the same lines. The exact list differs per tracker, so check the tracker page before you start.

Example: a page that already has a 1080p x264 encode can still take a 2160p x265 HDR encode, because resolution, codec and dynamic range all differ.

## Dupe, trump, REPACK

| Word | Meaning |
| --- | --- |
| **Dupe** | Your release would fill a slot that is already taken. Rejected. |
| **Trump** | A new release replaces an existing one in the same slot, and the old one is deleted. Each tracker lists what counts as a valid reason. Common ones: the old release is broken, has no seeders, or is worse in a way the rules name. |
| **REPACK** | A fixed version from the same group, for example after a bad audio sync. It replaces the group's own release. |
| **PROPER** | A fix by a different group for a broken release. |

<Callout tone="careful" label="Check" title="Better quality is not always a valid trump">
  Some trackers let a better encode replace a worse one. Others keep the first release in the slot unless it is broken. Read the trump rules on each tracker before you spend a weekend on an encode.
</Callout>

## Before you start any work

<Steps>

1. Search the tracker for the film by IMDb or TMDb ID, not by title.

2. Write down which slots exist. Check each one against the table above.

3. Check the tracker's rules for your release type. The tracker comparison shows the basics side by side.

4. Only then pick a source and start.

</Steps>

## Where uploads pay off the most

| What | Why |
| --- | --- |
| Older and less known films | Often no release at all on the tracker, so every slot is free. |
| Films you already have on disc | No cost to you beyond ripping time. |
| A codec slot nobody filled | Example: a UHD disc exists but nobody made a 1080p or 2160p x265 encode from it. |
| New releases | Only if you are fast. Many people race for these slots. |
