Go through **Every upload** first, then the list for your release type. Tracker-specific rules are on each tracker page. Each line has rejected an upload before.

## Every upload

<Checklist
  client:load
  id="every-upload"
  items={[
    { text: 'The slot is free. Search the tracker by IMDb or TMDb ID. Compare resolution, codec, HDR, edition and tier.' },
    { text: 'One .mkv, no folder (for single films). Look at what you are about to upload.' },
    { text: "Files not renamed, site title follows the tracker's naming rules. Original file name in qBittorrent, tracker page for the title format." },
    { text: 'Name matches the tracks. Resolution, source, audio codec, channels and codec in the name match MediaInfo.' },
    { text: 'Every track has a language. Check MediaInfo.' },
    { text: 'Subtitle rules met. English subtitle inside the MKV if the tracker needs it.' },
    { text: 'Duration matches the edition. Compare with DVDCompare or TMDb.' },
    { text: "The group is not banned on this tracker. Check the tracker's banned group list." },
    { text: 'The file stays where it is. qBittorrent seeds from the upload path.' },
  ]}
/>

## Release type

<Tabs>
<TabItem label="Remux">

<Checklist
  client:load
  id="remux"
  items={[
    { text: 'No x264 or x265 settings in the video. Check the MediaInfo Video section.' },
    { text: 'Full frame, black bars kept. 1920×1080 or 3840×2160.' },
    { text: 'Video bitrate at disc level. About 20 to 40 Mb/s (1080p), 40 to 100 Mb/s (UHD).' },
    { text: 'Main audio lossless where the disc has it, in the format the tracker requires. Check MediaInfo, then the tracker page.' },
    { text: 'Original audio mix kept. Mono or 2.0 originals on older films.' },
    { text: 'HDR present on UHD. Check the HDR format line in MediaInfo.' },
    { text: 'Chapters present. Check the Menu section in MediaInfo.' },
  ]}
/>

</TabItem>
<TabItem label="Encode">

<Checklist
  client:load
  id="encode"
  items={[

</TabItem>
<TabItem label="WEB-DL">

<Checklist

<Callout tone="careful" label="Check" title="Before you delete anything">
  If your downloads and library share files through hard links, deleting one name does not free space, and writing over one name changes all of them. Check the link count first (`stat -c %h file` on Linux).
</Callout>
