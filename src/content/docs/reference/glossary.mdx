## Trackers and torrents

| Term | Meaning |
| --- | --- |
| Private tracker | A torrent site with accounts, rules and ratio requirements |
| Torrent | The small file that tells your client what to download and from whom |
| Seeder | Someone with the full file who is uploading it |
| Leecher | Someone still downloading |
| Peer | Any seeder or leecher on a torrent |
| Snatch, completed | One full download of a torrent |
| Ratio | Uploaded ÷ downloaded |
| Buffer | Uploaded minus downloaded |
| Freeleech (FL) | A torrent whose download does not count against you |
| Double upload | Upload on that torrent counts twice |
| Hit and run (HnR) | Leaving a torrent before meeting its seeding requirement |
| Seed time | How long you seeded a torrent |
| Bonus points (BP) | Points earned for seeding, spent on upload credit or perks |
| Passkey | Your personal key inside each .torrent. Never share it. |
| Announce | The client telling the tracker how much you uploaded and downloaded |
| Cross-seeding | Seeding the same file to several trackers |
| Modq | Moderation queue. Where uploads wait for approval. |

## Releases

| Term | Meaning |
| --- | --- |
| Slot | One place on a title's page for one kind of release |
| Dupe | A release that would fill a slot already taken |
| Trump | A release that replaces an existing one in the same slot |
| REPACK | A group's fixed version of its own release |
| PROPER | Another group's fix for a broken release |
| Internal | A release by the tracker's own group |
| Personal release | Made by the uploader, not copied from elsewhere |
| Group | The team or person that made a release. Last part of the name. |
| NoGroup | Tag used when the maker is not in a group |
| Scene | Groups that follow the scene rules and release through topsites |
| P2P | Groups that release on trackers, outside the scene |
| Predb | A database of scene releases and their times |
| NFO | A text file with release details |
| Edition | A cut of the film: Theatrical, Director's Cut, Extended |
| Hybrid | A remux or encode built from several sources, for example US video with UK audio |

## Source and release types

| Term | Meaning |
| --- | --- |
| Full disc | The complete Blu-ray structure (BDMV) or ISO |
| BDMV | The folder structure of a Blu-ray |
| Remux | The main film copied off a disc into MKV, with no re-encoding |
| Encode | A re-compressed copy, smaller than the source |
| WEB-DL | The stream file from a service, saved without changes |
| WEBRip | A capture or re-encode of a stream |
| UHD | Ultra HD Blu-ray, 2160p, usually with HDR |
| Master | The digital version of the film a disc was made from |
| Upscale | A lower resolution stretched to look like a higher one. Rejected. |
| Transcode | Converting lossy to lossy. Loses quality twice. |

## Video

| Term | Meaning |
| --- | --- |
| Codec | The compression format: AVC, HEVC, VC-1, MPEG-2 |
| AVC, H.264 | The format of most Blu-rays and x264 encodes |
| HEVC, H.265 | The format of UHD discs and x265 encodes |
| x264, x265 | The encoders that produce H.264 and H.265 |
| Bitrate | Data per second. Mb/s or kbps. 1 Mb/s = 1000 kbps. |
| CRF | Constant rate factor. Encode to a quality level. |
| 2-pass | Encode to a bitrate in two passes |
| ABR | Average bitrate. 1-pass ABR is rejected on most trackers. |
| CBR | Constant bitrate. Rejected on most trackers. |
| Preset | How hard the encoder works: ultrafast to placebo |
| Tune | Settings for a type of picture: film, grain, animation |
| Bit depth | Bits per colour value: 8 or 10 |
| Crop | Removing black bars |
| Resize | Changing the frame size. Only ever downwards. |
| Frame rate | Frames per second. 23.976 for most films. |
| Interlaced | Old TV format with half-frames. Films on Blu-ray are progressive. |
| Hardsub | Text burned into the picture |
| Softsub | Subtitle as a separate track you can turn off |
| Bits per pixel | Bitrate divided by pixels per second. For comparing encodes. |
| Banding | Visible steps in smooth gradients like skies |
| Grain | Film texture. Hard to compress, easy to destroy with filters. |

## HDR

| Term | Meaning |
| --- | --- |
| SDR | Standard dynamic range |
| HDR10 | HDR with one set of brightness values for the whole film |
| HDR10+ | HDR with brightness values per scene |
| Dolby Vision (DV) | Dolby's HDR with values per scene. Comes in profiles (5, 7, 8). |
| PQ | The HDR brightness curve used by HDR10 and DV |
| HLG | Broadcast HDR curve |
| Mastering display | The screen the film was graded on, stored as metadata |
| MaxCLL, MaxFALL | Brightest pixel and brightest average frame in the film |
| Tonemapping | Converting HDR to SDR |

## Audio

| Term | Meaning |
| --- | --- |
| Lossless | Every bit of the original kept: TrueHD, DTS-HD MA, LPCM, FLAC |
| Lossy | Some data thrown away: DD, DDP, DTS, AAC, Opus |
| LPCM | Uncompressed audio. Usually converted to FLAC. |
| TrueHD | Dolby's lossless format |
| DTS-HD MA | DTS's lossless format |
| Atmos | Height channels on top of TrueHD or DDP |
| 2.0, 5.1, 7.1 | Channel count. `.1` is the subwoofer. |
| Downmix | Fewer channels made from more, for example 5.1 to 2.0 |
| zxx | Language code for "no spoken language" |
| und | Language code for "unknown" |

## Tools

| Term | Meaning |
| --- | --- |
| MediaInfo | Shows what is inside a media file |
| MKVToolNix | Edits MKV files without re-encoding |
| MakeMKV | Rips discs to MKV |
| StaxRip | Windows encoding front end for x264 and x265 |
| Upload Assistant (UA) | Prepares and uploads torrents to many trackers |
| eac3to | Converts and extracts audio from discs and MKVs |
| Subtitle Edit | Edits, syncs and converts subtitles |
