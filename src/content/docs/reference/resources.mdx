## Old advice to ignore

| Advice | Why not |
| --- | --- |
| HandBrake for release encodes | Several trackers reject or discourage it |
| A fixed CRF or bitrate for every film | Every film compresses differently. Run a test encode. |
| Denoise and deband filters by default | On a clean remux they remove detail and grain |
| 1-pass ABR "because it hits the size" | 2-pass hits the size too, and spends the bits better |
